## Projetos relevantes

### [Infraestrutura de Rede Virtualizada](https://github.com/gustavobarretomp/virtualized-network-scenario-1)

Implementação prática de uma infraestrutura virtualizada utilizando **Ubuntu Server, VirtualBox, FRRouting, RIPv2, BIND9 e Apache2**.

O projeto inclui cinco roteadores, múltiplas redes locais, servidores DNS e HTTP, configuração de interfaces com Netplan e testes de conectividade, roteamento e resolução de nomes.

### [Cenário 5 — DNS, HTTP e Serviços de E-mail](https://github.com/gustavobarretomp/network-scenario-5-email-services)

Projeto acadêmico de infraestrutura de redes envolvendo **RIPv2, DNS, registros A e MX, HTTP, SMTP e POP3**.

Participei como **Scrum Master**, auxiliando na organização, configuração, testes e documentação. Também desenvolvi o site do projeto e um roteiro de estudo sobre virtualização utilizando IA como apoio na organização dos conteúdos.
